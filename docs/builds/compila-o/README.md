# Portal Compila-o- · Releases

Página estática de releases do projeto A Link to the Past — Voxel Recomp, com navegação inspirada em páginas de repositório e releases do Forgejo.

URL esperada depois de ativar GitHub Pages no repositório `XDavi196/NEX`:
`https://xdavi196.github.io/NEX/builds/compila-o/`

## Limites importantes

- Este portal é hospedado no GitHub Pages; ele não executa nem hospeda o backend Forgejo.
- O repositório `XDavi196/Compila-o-` permanece privado.
- O portal não consulta a API de releases do repositório privado e não expõe tokens.
- A página só mostra a build #57 como compilação verificada; ela não a apresenta como uma release pública.
- A página de download só deve ser atualizada depois que um release real estiver publicado.
- Nenhuma ROM ou saída AOT gerada da ROM é publicada pelo portal.

## Publicação do site

O portal principal usa a pasta `/docs` da branch `main`. A página fica em `docs/builds/compila-o/`.
