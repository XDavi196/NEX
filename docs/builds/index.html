03 — GIT MIRROR

Forgejo / espelho do repositório

O portal está preparado para receber o endereço do repositório de compilação no Forgejo. Porém, forgejo.org/releases é a página de downloads das versões do próprio Forgejo — não é uma conta ou servidor onde criar o repositório da XDavi196.

Codeberg é uma plataforma baseada em Forgejo, mas não oferece hospedagem privada de repositórios. Como Compila-o- está privado no GitHub, manter essa privacidade exige uma instância Forgejo própria ou outro host que aceite repositórios privados. Torná-lo público no Codeberg só deve acontecer com autorização explícita e após revisar a licença. O espelho ainda não foi conectado e nenhum código privado foi publicado.
